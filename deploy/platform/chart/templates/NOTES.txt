  curl {{ include "forge.dexURL" . }}/dex/.well-known/openid-configuration
  curl http://{{ include "forge.apiHost" . }}/healthz

If the pods aren't starting, the Secrets this chart expects to already
exist are the usual cause:

  kubectl -n forge get secret forge-github-app dex-github{{ if not .Values.database.managed }} {{ .Values.database.secretName | default "forge-db-app" }}{{ end }}

(github_app_private_key on the first, client_id/client_secret on the
second{{ if not .Values.database.managed }}, uri and password on {{ .Values.database.secretName | default "forge-db-app" }}{{ end }}.)
See docs/forge/17-running-your-own-forge.md in showmino/techdocs for how to
create the first two from your GitHub App.
{{- if not .Values.database.managed }}

database.managed is off: you're bringing your own Postgres-compatible
database. Before this release can come up, create the Secret
{{ .Values.database.secretName | default "forge-db-app" }} in namespace forge yourself, with:
  uri: a full connection string for forge-api, e.g.
    postgres://{{ .Values.database.user | default "forge" }}:<password>@{{ .Values.database.host | default "forge-db-rw.forge.svc" }}:{{ .Values.database.port | default 5432 }}/forge?sslmode=require
  password: just the password (Dex's config needs it as a separate field)
and make sure a second database named {{ .Values.database.dexDatabase | default "dex" }} already exists on that
server, owned by {{ .Values.database.user | default "forge" }} -- for Dex's own sessions, separate from
forge-api's catalog.
{{- end }}

Make sure the GitHub App's callback URL is exactly:

  {{ include "forge.dexURL" . }}/dex/callback

{{- if .Values.deploys.enabled }}

deploys.enabled is on: your Argo CD instance also needs a pull credential
for oci://ghcr.io/{{ include "forge.chartRepo" . }} before any service can
actually deploy -- Argo CD falls back to an anonymous pull and fails with a
plain 401 if this is missing or wrong, not a clear error. The same page
above has the exact Secret shape and the three independent ways to get it
wrong.
{{- end }}
